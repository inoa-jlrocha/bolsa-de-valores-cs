# Simulador de Bolsa de Valores - Trading System

Este é um projeto em C# focado no desenvolvimento de um motor de simulação e casamento de ordens de compra e venda (Matching Engine) para o mercado financeiro.

## 🚀 Tecnologias
- .NET 10.0 / C#
- Git & GitHub

- [ ] Fase 2: Simulação em Tempo Real (Async/Events)
- [ ] Fase 3: Banco de Dados (EF Core + SQLite)
